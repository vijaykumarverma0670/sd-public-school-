# 🏫 S. D. Public School - Official Web Portal

Full-stack MERN web application built for **S. D. Public School**, BBC Road, Giridih.

## 🌟 Key Features
- **Notice Board:** Live alerts and dynamic announcements.
- **Result Portal:** Online student marksheet lookup by Class and Roll Number.
- **Admin Dashboard:** JWT-authenticated portal to manage gallery photos, notices, and desk messages.
- **Admission Inquiries:** Direct integration for student application processing.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Storage & Security:** Multer file uploads, JWT Authentication
