# 🏫 S. D. Public School - Web Portal

An interactive MERN stack web portal developed for **S. D. Public School**, located at BBC Road, Giridih, Jharkhand.

## ✨ Key Features
- **Dynamic Notice Board:** Real-time updates for school announcements.
- **Online Result Portal:** Search and print marksheets by entering Class and Roll Number.
- **Admin Dashboard:** Secure authentication to upload gallery photos, update leadership desks, and manage records.
- **Admission Inquiry Form:** Direct integration for student enrollment inquiries.
- **Responsive Gallery:** Dynamic media display powered by Node.js backend & MongoDB.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ORM)
- **File Storage:** Multer (Local Storage Middleware)
- **Authentication:** JSON Web Tokens (JWT)
